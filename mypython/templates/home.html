🚀 SAVVY Stock Dashboard API

Welcome to the SAVVY Stock Dashboard Platform - Real-time stock data and market insights

📊 Available Endpoints

Single Stock Data

GET /api/stock/{ticker}

Example: /api/stock/AAPL?period=1mo&interval=1d

Multiple Stocks

POST /api/stocks/multiple

Body: {"tickers": ["AAPL", "MSFT", "GOOGL"]}

Health Check

GET /api/health
